Celebrity proportion database builder

Maintainer tool. For each name it fetches the Wikipedia lead image (via the public API, CORS-enabled), runs the same on-device MediaPipe engine as the site, and keeps only the proportion numbers. No images are stored. Photos that are turned, tilted or have an open mouth/big smile are skipped. Format: one Name|f or Name|m per line (Wikipedia article title).
